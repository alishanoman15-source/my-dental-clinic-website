# Dentia - Premium Dental Clinic Website

A modern, fast, and fully responsive dental clinic website built with React and Tailwind CSS. The interface is optimized for excellent user experience and maximum conversion rates.

![Dentia Desktop Preview](/image.png)
![Dentia Mobile View Preview](/image-1.png)

## Core Features Implemented

- Minimalistic Responsive Header: Features a custom left-aligned sliding hamburger menu for mobile and tablet views.
- Dynamic UX Animations: Main header logo automatically transitions smoothly between center and right alignments based on the navigation drawer active state.
- Enhanced Sidebar Navigation: Clean layout inside the slide drawer featuring tree-structured sub-menus with custom vector icons and precise card-style link highlights.
- Integrated Call-to-Action (CTA): Single, high-contrast professional Book Appointment button strategically embedded inside the navigation tree.
- Polished Service Pages: Unified breadcrumb-driven banner section for seamless exploration across specialized dental categories.

## Tech Stack Used

- Frontend Framework: React.js
- Styling Engine: Tailwind CSS
- Navigation and Routing: React Router DOM
- Vector Icons Library: React Icons (Io5, Fa, Fa6)
